# Development Phase Verification Rules

Before proceeding to another development phase, verify that the current phase is fully functional.

Do not assume that code works simply because it has been generated.

Execute the appropriate commands and tests.

Check:

- PHP syntax.
- Laravel configuration.
- Database connectivity.
- Database migrations.
- Routes.
- Controllers.
- Models.
- Views.
- Authentication.
- Validation.
- Browser console errors where applicable.

Fix all errors discovered.

Do not modify previously completed functionality unnecessarily.

Update PROJECT_PROGRESS.md.

Provide a report showing:

1. What was implemented.
2. What was tested.
3. What passed.
4. What failed.
5. What was fixed.
6. Whether the phase is ready for approval.

Do not proceed to the next phase without confirmation.
